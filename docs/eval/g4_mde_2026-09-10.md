## Which comparisons this governs, and which it does not

This MDE is for **two independently trained arms** -- different checkpoints, so
each arm carries its own training-trajectory noise and the comparison is unpaired.
That is the right model for §5's Stage 2 questions (does the retrained detector
differ from what is deployed) and for any arm-vs-arm claim over fresh checkpoints.

**It is the wrong model for §6's mechanism arms and must not be used to cut them.**
S0-S8 vary the fusion mechanism over the *same* checkpoints and the *same* frames:
S1 real sigma against S3 shuffled sigma is one cache scored two ways. Seed variance
is common to both sides and cancels, so their resolution is set by §8's moving-block
bootstrap over frames, not by seed count -- which is why §8 specifies that interval
and the 0.0060 floor rather than a power calculation. Applying the number above to
them would cut arms that are in fact well resolved.

A paired between-seed sigma for the mechanism arms is not estimable from these
tables, which hold one number per run and no per-frame scores. It does not need to
be: the block bootstrap measures it directly when §6 runs.

## Verdict

* **VIS: 5 seeds do NOT resolve the floor** (MDE 0.01291 > 0.006). Would need **19 seeds/arm**.
* **IR: 5 seeds do NOT resolve the floor** (MDE 0.01010 > 0.006). Would need **12 seeds/arm**.

Per G4, an arm whose MDE exceeds the effect it exists to resolve is given more seeds or cut here, before it runs -- §9's BUDGET-CUT.

**Caveats on sigma, both of which cut against over-reading the seed counts above.**
The VIS estimate rests on 2 variants and 4 degrees of freedom; it is the noisiest
input in this calculation and its implied seed count should be read as an order of
magnitude, not a target. Both estimates come from stride-4 runs on other
architectures, at a different frame count from Stage 2's, and between-seed spread
is not guaranteed to transfer across either. They are nevertheless the only
multi-seed training-variance measurements this project holds, and G4 has to be
answered before Stage 2 produces a better one -- so the honest reading is that
**5 seeds are very unlikely to resolve 0.0060 for a trained-arm comparison**, not
that 19 is the precise number.
